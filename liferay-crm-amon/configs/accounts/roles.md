# Account Roles CRM Amon

| Role | Companies/People/Opps/Tasks/Notes | Admin Account/Offices/Users |
|------|-----------------------------------|-----------------------------|
| Account Admin | CRUD | CRUD |
| Manager | CRUD | Read offices/users |
| Sales | CRUD own + read account | — |
| Viewer | Read | — |

**Important :** ne pas accorder de Regular Role `View` global sur les Objects CRM (casse le multi-tenant).
